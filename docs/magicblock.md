# MagicBlock

Hot market state is delegated as a complete writable cluster: arenas, seats,
funding, event ring and per-seat scratch. Vaults, deposits, withdrawals and
durable authorities remain L1-only. The configured commit interval is 30,000
ms. Routed transactions reject mixed writable domains. ER lifecycle and CPI
execution are unverified pending a compatible SBPF runtime and validator.
